Novidades do mundo Flexbox

O Flexbox (Flexible Box Layout) é um modelo de layout unidimensional para CSS. Ele serve para distribuir o espaço entre os itens de uma interface e melhorar suas capacidades de alinhamento.

Por que usar Flexbox?

Ele facilita a centralização de elementos, altera a ordem de exibição dos blocos de forma dinâmica e ajusta os tamanhos para que tudo caiba perfeitamente na tela do celular ou do computador.
